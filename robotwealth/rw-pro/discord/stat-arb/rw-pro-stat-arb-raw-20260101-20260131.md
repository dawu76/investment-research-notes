1/10/26, 2:18 PM | strvinmarvin: First it takes S&P 500 and Nasdaq stocks and runs them through a lasso regression filter - that's straight from the course cointegration module. It uses the first year of data to train that filter, and that data never gets touched again for trading. The lasso filter spits out about 525 "approved" pairs that show good cointegration properties.

From there, we trade the next ~9 months out-of-sample. Every rebalance window, it ranks those pairs by LSR score combined with Euclidean distance - that's the pair selection methodology from the course. The spread z-scores drive the actual entry/exit signals. Those are saved to disk.

Where I deviated from the course: instead of a single lookback period, I added a triple-period confluence filter. Pairs have to rank in the top 50 at three different lookbacks (350, 210, and 150 bars) to qualify. This filters out pairs that only look good at one timescale. I also added a half-life filter (must mean-revert within ~10 days) and a sector cap (max 2 pairs per sector to avoid concentration).

I'm doing this now. or let me know if I missed it in the demo notebook. def _rank_linear_raw(pair_factor: pd.Series, eligible_mask: pd.Series) -> pd.Series:
    """Assign a +1..-1 linear ramp by rank (ascending pair_factor) over eligible tickers."""
    pf = pd.to_numeric(pair_factor, errors="coerce").astype(float)
    eligible = eligible_mask.reindex(pf.index).fillna(False).astype(bool)
    out = pd.Series(0.0, index=pf.index, dtype=float)

    idx = pf[eligible].sort_values(ascending=True).index
    m = int(len(idx))
    if m == 0:
        return out
    if m == 1:
        out.loc[idx[0]] = 1.0
        return out
    ramp = np.linspace(1.0, -1.0, num=m, dtype=float)
    out.loc[idx] = ramp
    return out

apply_max_weight_ls <- function(df, max_weight = 0.05, max_iter = 20) {
  for (i in seq_len(max_iter)) {
    if (!any(abs(df$weight) > max_weight + 1e-9)) break

    df <- df |>
      mutate(side = sign(weight)) |>
      group_by(date, side) |>
      mutate(
        original_gross = sum(abs(weight)),
        capped = sign(weight) * pmin(abs(weight), max_weight),
        weight = capped * original_gross / sum(abs(capped))
      ) |>
      ungroup() #|>

  }

  if (any(abs(df$weight) > max_weight + 1e-9)) {

  }

  df
}

library(tidyverse)
library(RcppRoll)

volume_features <- prices %>%
  arrange(ticker, date) %>%
  group_by(ticker) %>%
  mutate(
    log_volume = log(volume),
    # rolling mean and sd of log volume - trailing 20-day window
    vol_mean_20 = roll_mean(log_volume, n = 20, align = "right", fill = NA),
    vol_sd_20 = roll_sd(log_volume, n = 20, align = "right", fill = NA),
    # time-series z-score
    vol_z_ts = (log_volume - vol_mean_20) / vol_sd_20
  ) %>%
  ungroup() %>%
  # cross-sectional z-score of the TS z-scores each day
  group_by(date) %>%
  mutate(
    vol_z_xs = (vol_z_ts - mean(vol_z_ts, na.rm = TRUE)) / sd(vol_z_ts, na.rm = TRUE)
  ) %>%
  ungroup() %>%
  select(ticker, date, close, volume, log_volume, vol_z_ts, vol_z_xs)


Then join back on to your flattened spreads data to calculate the assymmetry feature:


df <- df %>%
  inner_join(
    volume_features %>% select(ticker, date, vol_z_xs),

  inner_join(
    volume_features %>% select(ticker, date, vol_z_xs),

  ) %>%
  rename(vol_z_xs_b = vol_z_xs) %>%
